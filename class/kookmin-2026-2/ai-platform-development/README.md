# 국민대 2026년 2학기 · AI플랫폼개발

## 자료와 제출 흐름

강사 원본 레포 → 학생별 포크 → 개인 작업·커밋·푸시 → 강사 평가.

- 강사 원본에서는 수업 자료만 가져옵니다. 학생 결과를 원본 레포에 PR로 제출하지 않습니다.
- 개인 작업을 먼저 Commit한 뒤 main에서 `git pull --no-rebase upstream main`으로 원본 변경을 합치고, `git push origin main`으로 자기 포크에 반영합니다.
- 강사 제공 파일은 직접 수정하지 않고, 주차별 `submissions/`에 결과·수정 기록을 저장합니다.
- `submissions/`는 Git 추적 대상입니다. 자기 포크에 커밋·푸시한 내용을 평가합니다.
- 업데이트 충돌 시 학생 결과를 덮어쓰거나 강제 동기화하지 않고 강사에게 확인합니다.
- 학생별 포크 URL은 수업 안내 채널로 제출합니다. 주차별 마감 시점의 커밋을 평가 기준으로 확인합니다.
