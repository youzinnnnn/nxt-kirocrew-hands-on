# 다음 주 과제 · 새봄 보드게임 교류회

[시작하기.html](시작하기.html)을 브라우저에서 열어 진행하세요. 모든 규정·행사·거래는 수업용 가상 자료입니다.

## 목표
새 자료를 지식기반에 등록하고, 근거와 전체 CSV 계산을 연결한 운영 보고서 HTML을 만듭니다. 앞의 빛담 사례와 독립된 B01 행사입니다.

## 진행
1. mission/documents의 문서 6개를 별도 지식 소스로 등록하고 처리 상태와 검색 결과를 확인합니다. 빛담 문서와 섞이지 않게 검색 범위 또는 소스를 확인합니다.
2. 승인된 정원, 지원금 사용 조건, 회계·구매 기준을 찾아 원문을 확인합니다. 필요한 근거를 대화에 연결합니다.
3. mission/data의 CSV 3개를 Python으로 전체 읽어 참가 현황, 재원별 현재 잔액과 B01 순지출, 확정 인원 기본안과 180명 확대안 구매계획을 계산합니다.
4. data-to-html 스킬을 재사용해 운영 보고서 HTML을 만들고 mission/submissions에 저장해 브라우저에서 확인합니다. 필요한 입력 형식은 자신의 스킬에 맞게 정합니다.

## 보고서에서 답할 질문
- 현재 참가 현황과 재원별 잔액은 어떤가요?
- 현재 확정 인원으로 준비하려면 무엇을 확인해야 하나요?
- 180명 확대안에는 어떤 승인과 재원 확인이 필요한가요?
- 외부 대학 학생도 참여할 수 있다고 확정할 근거가 있나요?

## 결과물
판단에 사용한 문서 근거와 계산 결과가 보이는 HTML 보고서를 남깁니다. 함께 만든 코드·JSON·확인 기록 등은 자유롭게 보관하세요. 정해진 파일 이름·개수·크기를 맞출 필요는 없습니다. 결과를 mission/submissions에 저장해 실제로 열어 확인하고, 다음 주까지 최종 HTML 파일을 수업 Slack에 첨부해 제출하세요. 원본 문서와 CSV는 보존합니다.

문서 전체를 매번 붙여 넣는 대신 질문에 필요한 근거를 찾으세요. CSV 집계는 검색으로 얻은 일부 행이 아니라 원본 전체를 사용하세요.
