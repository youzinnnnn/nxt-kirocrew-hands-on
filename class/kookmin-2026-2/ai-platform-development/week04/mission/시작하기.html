새봄 보드게임 교류회

새 자료로 지식을 등록하고
근거가 있는 운영 보고서 HTML을 만들어보세요.

앞의 빛담 사례와 별도인 B01 행사입니다. 모든 규정·행사·거래는 수업용 가상 자료입니다.

이번 상황

신청이 늘어나 운영진이 행사 규모 확대를 검토하고 있습니다. 학교 승인서, 동아리 규칙, 회의 메모와 실제 회계를 함께 살펴보고 준비 가능한 운영안을 제안하세요.

자료구성사용 방법
documents문서 6개별도 지식 소스로 등록 후 검색
data신청 240건 · 회계 40건 · 구매계획 4개Python으로 CSV 전체 계산
submissions내 결과물 저장 위치HTML을 직접 열어 확인

진행 순서

  1. 지식 등록
    mission/documents를 별도 소스로 등록하세요. 처리 상태와 실제 검색 결과를 확인하고 빛담 자료와 검색 범위가 섞이지 않게 하세요.
  2. 근거 연결
    정원, 지원금 사용 조건, 회계·구매 기준을 검색해 원문을 확인하고 필요한 근거를 대화에 연결하세요.
  3. 전체 계산
    mission/data의 CSV 3개로 참가 현황, 재원별 잔액과 B01 순지출, 확정 인원 기본안과 180명 확대안의 구매계획을 계산하세요.
  4. 보고서 작성
    앞에서 만든 data-to-html 스킬을 재사용하세요. 자신의 스킬에 맞게 입력을 준비하고, 근거와 계산 결과를 운영 보고서 HTML로 정리하세요.
  5. 저장과 확인
    mission/submissions에 저장하고 브라우저에서 직접 확인한 뒤, 다음 주까지 최종 HTML 파일을 수업 Slack에 첨부하세요.

보고서에서 답할 질문

  • 현재 참가 현황과 재원별 잔액은 어떤가요?
  • 현재 확정 인원으로 준비하려면 무엇을 확인해야 하나요?
  • 180명 확대안에는 어떤 승인과 재원 확인이 필요한가요?
  • 외부 대학 학생도 참여할 수 있다고 확정할 근거가 있나요?

제출 기한과 완료 기준

다음 주까지 · mission/submissions에 저장 · 최종 HTML은 수업 Slack에 제출

판단에 사용한 문서 근거와 계산 결과가 보이는 HTML 보고서가 있으면 됩니다. 함께 만든 코드·JSON·확인 기록도 자유롭게 남기세요. 파일 이름·개수·크기는 예시와 같을 필요가 없습니다.

원본 파일은 보존하세요. 근거가 없으면 확인 필요로 표시하고, CSV 합계는 전체 행으로 계산하세요. 승인받은 금액과 실제 입금, 확대 요청과 정원 승인을 구분해 보세요.

직접 질문하고, 근거를 찾고, 결과를 확인하는 미션입니다. 완성 프롬프트와 정답 보고서는 제공하지 않습니다.
