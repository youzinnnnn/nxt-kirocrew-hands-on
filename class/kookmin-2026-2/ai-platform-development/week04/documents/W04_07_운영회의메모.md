# 빛담 운영회의 메모
문서 ID: MEMO-04 / 작성일: 2026-09-18 / 행사 ID: E04

홍보에는 180명으로 안내했지만 현재 장소 승인 정원은 160명이다.
대기자를 더 받기 위해 180명으로 정원 변경을 요청할 예정이다. 아직 변경 승인을 받았다는 기록은 없다.
기념품은 회비로 처리하는 안을 논의했다. 학교 지원금 사용 가능 여부는 별도 지침을 확인한다.
인화비 중 용도가 적히지 않은 건은 영수증과 사용 목적을 다시 확인한다.
외부인 참가 조건은 이 회의에서 결정하지 않았다.
