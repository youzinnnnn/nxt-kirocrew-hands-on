# club-budget-check

동아리 행사의 CSV 3종(참가신청·회계내역·구매계획)을 **코드로 전체 집계**한다. 값 판단은 사람이 결과 JSON을 열어 근거 문서와 대조한다. 특정 행사·값에 묶이지 않고 인자로 받아 범용으로 쓴다.

## 무엇을 계산하나
1. **참가 상태별 인원** — 지정 행사(`--event`)의 신청상태별 카운트.
2. **확정자 선택** — 신청상태='확정'만 대상으로, 참가신청 CSV의 옵션 컬럼(고정 5열 외)별 값 분포. `신청/미신청/받지않음/빈칸`을 구분.
3. **재원별 현재 잔액** — 기초잔액 + 수입 + 환불입금 − 지출 − 환불지급.
4. **행사 순지출** — 해당 행사의 지출 + 환불지급 − 환불입금 (수입 제외).
5. **구매계획** — 인원 시나리오별 예정비용. `참가자`=인원×계수, `고정`=계수, 예정비용=단가×수량. 확정 인원 시나리오는 자동 포함.
6. (선택) **지원금 승인 대조** — 총 한도·1차 지급·1차 거래 ID를 회계에서 확인.

## 근거 문서와 조항 (값이 아닌 규칙만 코드에 반영)
- **ACCOUNT-01** 회계 집계 기준: 제2조 부호(수입·환불입금 +, 지출·환불지급 −), 제3조 현재잔액·행사 순지출 산식, 제5조 구매 수량 산식.
- **CLUB-01** 동아리 운영 규칙 제1조: 구매 기본 인원 = 확정 인원. 대기자는 확정에 미리 더하지 않음(제3조).
- **RULE-01** 학교지원금 지침 제5조: 미입금 승인액은 현금에 가산하지 않음. 제3조 지원 제외(기념품·개인 선물 등).

**중요:** 기초잔액·정원 시나리오·지원금 한도 같은 '값'은 하드코딩하지 않는다. 근거 문서에서 확인한 값만 인자로 넘기고, 안 넘긴 값은 결과의 `확인_필요`에 남는다.

## 원칙
- 파이썬 3.10+ **표준 라이브러리만** (`csv`, `json`, `argparse`, `pathlib`). 외부 패키지·네트워크 없음.
- CSV는 `utf-8-sig`로 읽어 BOM 대응. 금액은 정수 원 단위.
- **원본 CSV는 읽기 전용.** 출력은 `--out` JSON에만 쓴다.
- 구매계획은 **예정 수량 계산**이며 이미 처리된 회계 거래에 합산하지 않는다(ACCOUNT-01 제4조).

## 입력 인자
| 인자 | 필수 | 설명 |
|---|---|---|
| `--data` | ✔ | CSV 폴더 (참가신청·회계내역·구매계획 `.csv`) |
| `--out` | ✔ | 결과 JSON 경로 |
| `--event` | ✔ | 행사 ID (예: `E04`) |
| `--opening` | | 재원별 기초잔액 (예: `학교지원금=0 동아리회비=800000`) |
| `--headcounts` | | 구매 인원 시나리오 (예: `140 160 180`). 확정 인원은 자동 포함 |
| `--fund-name/--fund-limit/--fund-first/--fund-first-txn` | | 지원금 승인 대조 (선택) |
| `--event-name/--basis-date` | | 보고용 라벨 (선택) |
| `--signup/--account/--plan` | | CSV 파일명 오버라이드 (기본: 참가신청/회계내역/구매계획.csv) |

## CSV 스키마
- **참가신청**: `신청_ID, 행사_ID, 이름, 신청상태, 신청일, <옵션들…>` — 옵션 컬럼은 자동 인식.
- **회계내역**: `거래_ID, 거래일, 행사_ID, 재원, 유형, 항목, 용도, 금액, 증빙, 원거래_ID`.
- **구매계획**: `항목_ID, 물품, 수량기준, 계수, 단가, 예정재원, 용도`.

## 사용법 (PowerShell)
```powershell
cd C:\Users\1153g\.kiro\crew\skills\club-budget-check
python .\scripts\aggregate.py `
  --data "<week04>\data" `
  --out  "<week04>\submissions\집계_E04.json" `
  --event E04 `
  --opening 학교지원금=0 동아리회비=800000 `

  --fund-name 학교지원금 --fund-limit 1500000 --fund-first 1000000 --fund-first-txn T091 `
  --event-name "빛담 가을사진전과 인화 체험" --basis-date "2026-09-22"
echo "EXIT=$LASTEXITCODE"
```

## 종료 코드
- `0` 성공(JSON 생성)
- `1` 입력 오류(폴더/파일 없음, 인자 형식 오류)
- `2` 처리 오류(CSV 파싱·컬럼 누락 등)

## 확인
결과 JSON의 `확인_필요` 배열을 먼저 본다. 기초잔액 미제공·예상외 회계 유형·누락 거래 등이 여기에 남는다. 참가 상태별 합이 해당 행사 행수와 같은지, 확정 인원이 구매계획 '참가자' 곱에 반영됐는지 대조한다.
