# 5주차 · 작업 명세와 실행 검증

모든 상황·기관·공지는 수업용 가상 자료입니다. 실제 학교 규정이나 서비스와 무관합니다.

## 자료 안내

Task Runner의 Workspace는 `week05`입니다.

```text
week05/
├── 시작하기.html
├── practice/                 # 따라하기 입력·검사기
├── mission/                  # 독립 미션 입력
└── submissions/
    ├── practice/
    │   ├── run01/
    │   └── run02/
    └── mission/              # 명세.md, 브리핑.md, 확인기록.md
```

따라하기에서는 시작하기 2번의 제공 프롬프트를 입력한 뒤 다듬어진 명세를 검토합니다. 별도 초안 파일은 작성하지 않습니다. 독립 미션에서는 직접 기준을 정하고 Task Runner로 실행합니다.

먼저 [시작하기.html](시작하기.html)을 브라우저로 여세요. 단계별 안내와 복사용 요청, 제출 파일 목록을 볼 수 있습니다.

1. [따라하기: 창고 재고 점검](practice/README.md)에서 작은 작업의 명세를 작성하고 실행 결과를 검사합니다.
2. [독립 미션: 캠퍼스 공지 브리핑](mission/brief.md)에서 같은 과정을 새로운 자료에 적용합니다.
3. 창고 실습은 [따라하기 확인 기록 틀](검증기록_틀.md), 공지 미션은 [미션 확인기록 양식](mission/templates/확인기록.md)을 사용합니다.

먼저 원래 week05의 submissions에서 결과 파일을 확인합니다. 없으면 Task Runner의 채팅에서 파일 위치와 브랜치를 확인하고, 결과가 다른 브랜치에 있으면 main 병합을 요청합니다.

입력 자료는 보존합니다. 자신이 만드는 명세·코드·결과·검증 기록은 submissions/practice 또는 submissions/mission 안에 둡니다. 실행 전후 결과를 서로 덮어쓰지 않도록 구분하세요. 런타임이 남기는 파일은 별도로 확인합니다.

이 폴더에는 완성된 미션 해답이 없습니다. practice/cases는 검증 수업에서 열어볼 정상·오류 결과 예제입니다.
