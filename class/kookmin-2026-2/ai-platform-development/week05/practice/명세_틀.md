# 작업 명세

명세의 구성 항목을 살펴보는 참고 자료입니다. 따라하기에서는 이 틀을 별도 파일로 작성하지 않고, 제공 프롬프트로 정제한 명세에 아래 항목이 담겼는지 확인합니다.
독립 미션에서 직접 명세를 작성할 때 필요하면 이 구성을 참고하세요. Workspace는 week05이며, 미션 명세와 결과는 submissions/mission에 저장합니다.

## 업무 목적
누가 어떤 판단에 사용할 결과인가요?

## 입력
읽을 파일과 데이터의 의미를 적으세요.

## 결과물
JSON·보고서와 최종 저장 위치를 적으세요.

## 업무 기준
저재고의 집계 단위와 비교 조건을 적으세요.

## 허용 변경
원본 보존과 코드·중간 결과·최종 결과의 허용 위치를 적으세요.

## 완료 조건
조건마다 검사 수단을 적으세요. 파일 생성뿐 아니라 내용과 종료 후 접근 가능 여부를 포함하세요.

## 실행 전 검토
자동으로 정제된 명세에서 추가된 가정, 빠진 조건, 고친 부분을 기록하세요.
