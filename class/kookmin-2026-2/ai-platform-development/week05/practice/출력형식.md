# 따라하기 결과 형식

모든 경로는 Workspace인 week05 기준입니다. 1차 결과는 submissions/practice/run01, 2차 결과는 submissions/practice/run02, 경계값 결과는 submissions/practice/boundary에 저장합니다.

result.json은 다음 구조를 사용합니다. 아래 값은 구조 설명용 빈칸이며 완성 결과가 아닙니다.

```json
{
  "source_files": [],
  "warehouse_totals": {},
  "item_totals": {},
  "grand_total": 0,
  "low_stock_basis": "item_total",
  "threshold": 5,
  "low_stock": []
}
```

- source_files: 사용한 입력 파일 이름의 목록.
- warehouse_totals: 창고 이름과 정수 합계의 대응. 기본 자료는 A, B, C.
- item_totals: 원본에 등장한 품목 이름과 전체 창고의 정수 합계.
- grand_total: 전체 수량.
- low_stock_basis: 전체 품목 합계 기준은 item_total, 창고별 기준은 warehouse_row.
- threshold: 저재고의 상한. 수량이 이 값보다 작을 때 해당합니다.
- low_stock: 전체 기준은 {"item": "품목명", "quantity": 0}, 창고별 기준은 여기에 "warehouse"를 더합니다. 0은 형식 설명용입니다.

1차에서 선택한 기준과 목록이 일치해야 합니다. 제공 검사기는 2차 기준인 item_total, threshold=5를 검사합니다. 숫자는 문자열이 아닌 정수로 저장하세요.

짧은 Markdown 보고서에는 창고별 합계, 품목별 합계, 저재고 목록과 적용 기준을 포함합니다. JSON과 보고서의 수치를 대조하세요.
